# 这顿谁买单

一桌九道菜，其中一道藏着账单。2–6 位玩家共用一部手机，谁点中这道菜，谁就请客。游戏只记录结果。

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择「小游戏」，导入本仓库根目录。
2. 项目配置默认使用游客 AppID 做本地调试。若要真机预览或上传，请换成自己有权限的微信小游戏 AppID。
3. 点击「编译」，选好同桌人数，然后点「开一桌」。项目直接使用微信 Canvas 2D，无需安装依赖或构建。

## 怎么玩

- 开桌前按围坐顺序认好 1 号位到最后一位。请一人单独看屏幕，从九道菜里点一道作为本局的买单菜。想让所有点菜的人都不知道答案，可以请旁观者设菜。
- 封好菜后把手机交给 1 号位。每次只点一道，躲过就把手机传给下一位，已点的菜会从可选项中划掉。最后一位点完仍没命中，就轮回 1 号位继续。
- 谁点中买单菜，游戏就立即开小票，写上那个人的席号和菜名。「再来一桌」会清空菜单，由设菜人重新指定。
