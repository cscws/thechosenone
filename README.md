# 这顿谁买单

一桌人都想溜，一张账单只能落在一个人头上。2–6 位玩家共用一部手机，各自选座，再看看谁是今晚的买单人。游戏只抽人选，没有支付功能。

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择「小游戏」，导入本仓库根目录。
2. 项目配置默认使用游客 AppID 做本地调试。若要真机预览或上传，请换成自己有权限的微信小游戏 AppID。
3. 点击「编译」，选好同桌人数，然后点「开一桌」。项目直接使用微信 Canvas 2D，无需安装依赖或构建。

## 怎么玩

- 每人挑一个空碟点一下，记住自己的席号。大家可以同时点，也可以轮流传手机。松手后席位会保留。
- 人齐后自动开签，每个席位买单的机会相同。免单的人逐个揭晓，最后一席就是本桌买单人。
- 结果小票会亮出买单席号。点「再来一桌」可以用相同人数重玩，返回首页可以换人数。
